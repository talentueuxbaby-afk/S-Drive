# S-Drive — version simple pour GitHub

Cette version regroupe l'interface client, l'administration et le logo dans `server.js`.
Pour GitHub, il suffit de téléverser `server.js` et `package.json`.

Démarrage :
npm install
npm start

Client : /
Administration : /admin/

Variables recommandées sur l'hébergement :
ADMIN_USERNAME
ADMIN_PASSWORD
SESSION_SECRET
